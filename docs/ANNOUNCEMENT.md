# Introducing Clear Tool 2.2 — a clearer view of your Windows PC

**Hardware, games, storage and updates. One organized workspace.**

Clear Tool is now available as a free, open-source Windows desktop application. It brings everyday device information and maintenance tasks together, with English and Arabic interfaces and light/dark themes.

**[Download for Windows x64](https://github.com/Ahmed-Khalil-Mohamed/clear-tool/releases/latest) · [User guide](https://github.com/Ahmed-Khalil-Mohamed/clear-tool/blob/main/docs/USER-GUIDE.md) · [Source code](https://github.com/Ahmed-Khalil-Mohamed/clear-tool)**

![Clear Tool in English](https://raw.githubusercontent.com/Ahmed-Khalil-Mohamed/clear-tool/main/docs/images/overview-en.png)

## What can you do with it?

- **Understand your PC:** see detected hardware, installed applications and live performance readings.
- **Review updates:** inspect available application, Windows and driver updates, with measured download progress where the update tool provides it.
- **Inspect storage before cleaning:** preview defined cache categories, analyze folders and compare duplicate file contents.
- **Organize your games:** browse supported local libraries, use fullscreen ClearPlay, link emulators and explore Playnite add-ons.
- **Personalize your workspace:** switch languages/themes, use tray mode and an optional shortcuts widget, and connect Windows customization tools.

![Driver workspace in English](https://raw.githubusercontent.com/Ahmed-Khalil-Mohamed/clear-tool/main/docs/images/drivers-en.png)

## Try it and help shape what comes next

Choose the installer for everyday use or the portable executable to run without installing. The current build targets Windows x64 and has been physically checked on Windows 11. Read the release notes for requirements, unsigned-binary information and known limits. Windows/driver updates finish installation in Windows Update; add-ons finish installation in Playnite.

Project code is MIT licensed. Screenshots show a test machine; your hardware and update results will differ. Clear Tool makes no guaranteed FPS or fixed-space-recovery claims.
