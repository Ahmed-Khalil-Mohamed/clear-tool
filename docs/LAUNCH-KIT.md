## Arabic announcement

أطلقت **Clear Tool 2.2** — برنامج مجاني ومفتوح المصدر لويندوز يجمع متابعة الجهاز والصيانة اليومية في واجهة واحدة.

بدل ما تدور بين أماكن كتير، تقدر تشوف مواصفات جهازك، تراجع البرامج والتعريفات والتحديثات المتاحة، تفحص الكاش قبل تنظيفه، وتنظّم مكتبة ألعابك. كمان فيه كتالوج إضافات Playnite، ربط محاكيات، وأدوات لتخصيص ويندوز.

الواجهة عربية وإنجليزية، بثيم فاتح وداكن، وأيقونة قرب الساعة وويدجت للاختصارات. تقدم التنزيل يظهر حسب القياسات اللي بترسلها أداة التحديث، والبيانات المحلية تفضل على جهازك.

متاح بمثبّت أو نسخة محمولة لـWindows x64. الكود برخصة MIT، والمساهمات وتقارير المشاكل مرحب بها.

جرّبه واعرف أكتر: https://github.com/Ahmed-Khalil-Mohamed/clear-tool

التنزيل: https://github.com/Ahmed-Khalil-Mohamed/clear-tool/releases/latest

ملاحظة: لا يوجد وعد بزيادة FPS أو توفير مساحة ثابتة. تثبيت تحديثات ويندوز وإضافات Playnite يُستكمل عبر أدواتها، والنسخة الحالية غير موقّعة بشهادة نشر تجارية.

## English announcement

Introducing **Clear Tool 2.2**, a free, open-source Windows workspace for your hardware, games, storage and updates.

Review device specifications, installed applications and available driver updates. Inspect cache before clearing it. Bring supported game libraries together, browse Playnite add-ons and connect your preferred emulators and Windows customization tools.

Arabic and English. Light and dark. A tray app and optional shortcuts widget. Measured download progress, with clear states when an operation cannot report a percentage.

Available as a Windows x64 installer or portable application. Project code is MIT licensed. Contributions, translations and reproducible compatibility reports are welcome.

Explore: https://github.com/Ahmed-Khalil-Mohamed/clear-tool

Download: https://github.com/Ahmed-Khalil-Mohamed/clear-tool/releases/latest

This release makes no FPS or fixed-space-recovery promises. Windows updates and Playnite add-ons finish installation in their respective tools. Binaries are currently unsigned.
