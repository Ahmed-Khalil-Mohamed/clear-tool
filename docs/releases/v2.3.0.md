# Clear Tool 2.3.0 — Device Atlas

Your PC, with more context. This update adds an offline device and component atlas to Clear Tool's Windows workspace.

## What's new

- **42 brands and 110 device families:** search the local catalog and filter by manufacturer or form factor.
- **25 illustrations, including 14 new assets:** additional Dell, Alienware, ASUS, Lenovo, MSI, Acer, HP, Razer and Samsung family art, plus all-in-one, workstation, rugged and detachable form factors.
- **12 component categories:** inspect available CPU, GPU, memory-module, motherboard, physical-drive, display, network, audio and battery inventory. Case, cooling and PSU model information is explicitly unavailable when Windows cannot report it.
- **Better automatic matching:** enclosure types, model, system family and product version are considered. Manual picture choices never change detected hardware information.
- **English/Arabic and light/dark:** keyboard-accessible catalog, responsive layout and a one-click return to automatic artwork selection.

Open **Overview → Device catalog & components**. See the [full coverage inventory](https://github.com/Ahmed-Khalil-Mohamed/clear-tool/blob/v2.3.0/docs/DEVICE-ATLAS.md).

## Upgrade from 2.2

Quit the old version from its tray menu, then run **Clear-Tool-Setup-2.3.0.exe**. Portable users should place the new executable beside their existing **ClearTool-Data** folder and retain that folder. Back up settings before upgrading. Clear Tool does not have an automatic self-updater.

**SHA256SUMS.txt** contains checksums for the installer, portable executable and launch kit. GitHub's source archives contain source code, not the installer.

## بالعربية

تحديث **Clear Tool 2.3** يضيف كتالوجًا محليًا يشمل **٤٢ ماركة و١١٠ سلاسل أجهزة و٢٥ رسمًا توضيحيًا**، منها ١٤ رسمًا جديدًا، مع **١٢ فئة لمكوّنات الجهاز**.

من الرئيسية افتح **كتالوج الأجهزة والقطع** للبحث والفلترة، مشاهدة القطع المقروءة من ويندوز، أو تغيير الرسم والرجوع للاختيار التلقائي. اقفل الإصدار القديم من أيقونة البرنامج بجوار الساعة ثم شغّل المثبّت الجديد. للنسخة المحمولة احتفظ بمجلد **ClearTool-Data** وضع الملف الجديد بجانبه.

## Requirements and verification

- Windows 10/11 x64 target; physically tested on Windows 11 x64. Other families have fixture coverage, not universal hardware certification.
- **37 automated tests passed.** Native packaged checks covered filters, all images, manual selection without identity changes, component data, English/light, Arabic/dark, narrow layout, Escape dismissal and automatic reset; no renderer errors were observed.
- Illustrations represent families/form factors, not exact service diagrams or photos of every SKU. The existing ASUS FA607NUG exterior photo remains specifically sourced. Reference component brands are examples, not detected or guaranteed-compatible parts.
- Binaries are not signed with a commercial publisher certificate. Verify source and checksums; do not disable Windows protections.
- The existing games, reviewed cleanup, update and Windows tools remain available. This release does not claim new FPS gains or retesting every existing integration.
